# MNIST Classification

## Overview
A Machine Learning classification project using the MNIST handwritten digits dataset.

This project is based on concepts from *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* and includes experiments with different classification algorithms and evaluation techniques.

## Dataset
The MNIST dataset contains 70,000 handwritten digit images (0-9), where each image has 784 pixel features.

## Models & Techniques Used

- SGDClassifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- KNeighborsClassifier

Techniques:
- Binary Classification (detecting digit 5)
- Multiclass Classification
- Multilabel Classification
- Cross-validation
- Confusion Matrix Analysis
- Precision, Recall, F1 Score
- ROC Curve & AUC
- GridSearchCV Hyperparameter Tuning
- Data Augmentation
